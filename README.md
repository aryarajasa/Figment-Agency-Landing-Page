# Figment Agency Landing Page

Interactive landing page for Figment Agency, an organic search and Generative Engine Optimisation (GEO) agency based in London. Built with a clean, minimalist design inspired by ToDesktop.

## Tech Stack

- **HTML5 / CSS3**
- **Tailwind CSS (CDN)**
- **Vanilla JavaScript (ES6+)**
- **HTML5 Canvas 2D** — Custom 3D particle DNA helix wave with interactive cursor scattering and delayed spring regeneration
- **Instrument Sans** (Google Fonts)

## Features

- **Minimalist Design System**: Clean light background with subtle dotted matrix texture, tactile skeuomorphic primary actions, and 1px border hover feedback.
- **Interactive 3D Dotted DNA Canvas**: 60fps particle wave simulation positioned behind the hero mockup with kinetic cursor dispersion and smooth, delayed re-formation.
- **Interactive AI Search Simulator**: Live demonstration of AI citations across ChatGPT Search, Google AI Overviews, and Perplexity.
- **AI Opportunity Scanner**: Multi-step questionnaire estimating untapped citation share for clinics and professional firms.
- **Filterable Wall of Love**: Masonry review grid filtered by industry (Healthcare, Finance, Luxury).
- **Discovery Call & Guide Modals**: Lightweight lead capture forms with ESC-key and backdrop handling.
